# SearchForFiles 📚
Project to create a program to find files on computer using virtual threads and sqlLite for indexing

## Library used in this project
-  ⚙️ SqlLite: Small and optimized database. https://sqlite.org

## 🎯 Features until now
- ✅ Search using virtual threads in java 25.
- ✅ The search using sql database to indexing and monitoring changes in archives in real time.
- ✅ Parallel indexing of file(15.000 files per/second).
- ✅ Search by name, type, extension, size and date.
- ✅ LRU cache for frequents searches.
- ✅ Support for multiple drives.
- ✅ Basic interface in swing.
